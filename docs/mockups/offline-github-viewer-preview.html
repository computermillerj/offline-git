What the app looks like if PLAN.md is built as written

Android-first, dark dev-tool theme per the "Android Studio-like coloring" goal. Phones use list-to-detail navigation; the wide frame at the bottom is the later tablet/desktop two-pane mode. Every element maps to a plan section — nothing shown here is outside MVP scope except the final frame.

Deliberately absent, per the plan's non-goals

No editing, no commit creation, no review comments or approvals, no syntax highlighting beyond diff coloring (the token colors shown in the diff are the later milestone-7 polish — the MVP renders plain text in green/red/context). Binary and LFS files would appear in the file list marked "unsupported" instead of rendering.

The "source" chip in the diff header is the DiffProvider boundary made visible: "cached patch" = GithubPatchDiffProvider, "local blob diff" = LocalBlobDiffProvider fallback for truncated or missing patches.
